Free vs Pro

Free core. Tiny paid unlock.

The free app is the full proof loop: create the variation, add photos, price it, generate the PDF, capture local acceptance, lock the artefact, create proof hashes, send SMS proof, share the PDF and export CSV.

Pro is deliberately small at $2/month. It unlocks contractor branding on PDFs and Xero draft invoice export. The core evidence and acceptance workflow stays free.

Positioning

Variation records that hold up when someone argues later.

VariationProof is not just a quote tool. It converts messy site reality into defensible commercial evidence: outside scope, evidence, price, who approved it and when it was sent.

If it is not evidenced, priced, sent, and approved, it is not a variation. It is just a hope.

Install

How to check it on an Android phone.

1. Download the APK

Open this page on the Android phone and tap the download button. Keep the file only from this site.

2. Allow install if Android asks

Android may ask you to allow installs from the browser. This is normal for a direct APK test install.

3. Open VariationProof

Create a variation, add a photo, set company details/logo, review the PDF and confirm the share sheet opens.
